## Dependency notes

- 002–008 depend on 001 because each works on a branch and checks for drift
  against the baseline commit.
- 005 depends on 004 because both edit the error path in
  `extension/entrypoints/background.ts`.
- 007 requires 006: it rewrites the paid judging path and must not land
  without tests around the current behaviour.
- 007 should follow 003: once verdicts are cached, the rate limiter must be
  charged only for posts that miss the cache. 007's steps cover both orders.
- 002, 003 and 004 are independent of each other and can run in parallel.
- 008 needs a browser signed in to X; an automated executor will hand its
  first step back to the operator.
- 009 is best done last so the README describes the finished state.
- 010 was requested by the owner after the audit. It is independent of
  002–009, but if 006 has landed it adds two cases to that test file.

- A user can inflate their own hidden-post counter with made-up ids: affects
  only their own statistics.
- `pnpm audit` reports one low and one moderate advisory via the shadcn CLI's
  `deepmerge`: build-time tooling, not shipped code.
- Unverified Facebook selectors and the 280-character limit on long posts:
  already marked as known shortcuts in the code.
